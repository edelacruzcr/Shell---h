# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-25

### Añadido
- Versión inicial de `ayuda.sh` con más de 110 comandos documentados.
- Menú interactivo en terminal con 7 categorías principales y búsqueda inteligente.
- Paginación dinámica (15 elementos por página) con navegación simple (`n`/`p`).
- Fichas técnicas completas con sintaxis explícita, marcadores descriptivos y ejemplos reales.
- Comando de instalación y actualización rápida de una sola línea mediante `curl`.
- Licencia MIT y documentación completa.
